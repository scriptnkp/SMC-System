# 🔱 SMC Flow System – Mxwll Fusion Engine (XAUUSD Optimized)

An advanced Smart Money Concept (SMC) and Hybrid Market Structure Engine built on Pine Script v6. 

## 🚀 Features
- **Smart Money Concepts:** Auto-detects BOS, CHoCH, Highs, and Lows.
- **UT Bot Signals:** Adaptive ATR-based Trend Shifts with Label Management.
- **FVG & Order Blocks:** Identifies mitigated and unmitigated zones (LuxAlgo-inspired).
- **XAUUSD Dashboard:** Real-time display of current trend, active signals, total simulated trades, and dynamic Win Rate tracking.
- **Session Heatmaps:** Auto-color background based on Asian, London, and NY sessions.

## 🛠 Usage
Simply copy the code from `indicator.pine` and paste it into your TradingView Pine Editor. Save and add to your chart. Best optimized for XAUUSD on 5m, 15m, and 1H timeframes.
